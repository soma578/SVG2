# 1. SVGMapでしかできない（または圧倒的に向く）こと

## ① “任意の地図”を同一座標系で重ねる（ユーザー定義GIS）

Leaflet等でも出来ますが、SVGMapは **「最初からレイヤをDOMとして持つ」**ため、

* レイヤ同士の合成（透明度、順序、ブレンド感覚）
* レイヤの一部だけ強調（CSSで）
* 任意形状（ポリゴン・線・点）の表現
* 文字や注釈、凡例を含む「地図作品」的な統合

が圧倒的にやりやすいです。

> つまり「オープンデータを混ぜて“自分の地図”を作る」が強い。

---

## ② “点・線・面”を「意味」や「状態」で即座に可視化（スタイル駆動）

SVGはCSSで書き換えが効くので、**データ→表現**が強い。

* ポートを「危険度」「近さ」「目的別」で色・形・大きさを変える
* 避難所を「収容」「種別」「距離」で変える
* モード切替で表示意味が変わる（通学モード／防災モード）

これはGoogleの地図には載らない「あなたの評価軸の地図」です。

---

## ③ “地図上で議論できる”形にしやすい（注釈・説明・スナップショット）

SVGはそのまま印刷・共有・保存に強い。

* 研究・授業・発表用に「その状態の地図」を保存
* 凡例や注釈を地図に埋め込み
* レイヤ構成込みで共有

これもSVGの強みです。

---

## ④ （クリック不要でも）“空間的関係の判断”を支援できる

ルート計算で勝たなくても、SVGMapは

* “危険エリアの上にあるか”
* “安全圏にあるか”
* “避難所の分布と空白域”
* “ももチャリポート密度の偏り”

といった **空間的な意思決定**に強い。

## 1) 災害シミュレーション案は“CSS切替”が最強。ただし判定は事前計算が現実的

あなたの案の核心（`.mode-flood` でポートを死なせる）は正しいです。
ただ、**「浸水区域と重なるポート」をブラウザで衝突判定**は、いまの軽量化方針（ハザードはラスタ化）だと成立しにくいです。

### なぜ難しいか

* ハザードを `<image>`（ラスタ）にした場合、ブラウザ側で「このピクセルの浸水深」を簡単に参照できません（色＝意味の逆引きが必要）。
* なので、“当たり判定をブラウザでやる”よりも、**ポートごとの災害ランクを事前に付けておく**のが最短で確実です。

### 現実解（最短ルート）

**オープンデータ（ポートCSV）に、`flood_rank` / `landslide_rank` を付与してしまう**。

* オフライン（QGIS等）で「ポート点」×「浸水想定区域ポリゴン」を空間結合
* 結果として `flood_rank = 0/1/2/3`（例：浸水深ランク）を付加
* ブラウザは **ただCSSで表示を変えるだけ**

これなら、あなたの提示したCSSロジックがそのまま“動くロジック”になります。

> ここが重要で、SVGMapの勝ち筋は「計算の高度さ」ではなく「状態遷移が気持ちよく見える」ことです。判定は前処理でOK。

## 2) ボロノイ（勢力圏）案は「静的データだけで勝てる」ので非常に相性が良い

ボロノイは、リアルタイム無しでも価値が出ます。しかも **35ポート程度なら計算は軽い**。
「自転車アクセス偏差値」的な見せ方はまさに“文脈で勝つ”です。

### 実装上の注意（改善ポイント）

* D3の `d3.voronoi()` は古めなので、今は **d3-delaunay** の方が堅いです。
* あなたの座標系は `x=100*lon`, `y=-100*lat` が基準なので、投影は超簡単。

#### 例：d3-delaunay（D3 v7向け）概略

```javascript
import { Delaunay } from "https://cdn.skypack.dev/d3-delaunay@6";

const ports = portData.map(d => ({
  ...d,
  x: d.lon * 100,
  y: -d.lat * 100
}));

const extent = [13356.86, -3486.06, 13398.69, -3435.00]; // viewBox範囲（x0,y0,x1,y1）
const delaunay = Delaunay.from(ports, d => d.x, d => d.y);
const vor = delaunay.voronoi(extent);

const g = document.getElementById("layer-voronoi");
ports.forEach((p, i) => {
  const path = document.createElementNS("http://www.w3.org/2000/svg", "path");
  path.setAttribute("d", vor.renderCell(i));
  path.setAttribute("class", "voronoi-cell");
  path.dataset.portId = p.id;
  g.appendChild(path);
});
```

CSSは薄く敷くだけで成立します。

```css
.voronoi-cell { fill-opacity: 0.25; stroke: #fff; stroke-width: 0.05; }
```

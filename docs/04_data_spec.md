# 04_data_spec: データ仕様

## 1. 全体方針

- 防災マップで扱うデータは、以下の3種類に分ける。
  1. 避難所などのポイントデータ（CSV）
  2. ハザードポリゴン（SVGレイヤ）
  3. 共通座標スキーマ（schema）情報

- CSV は Git / サーバ上でテキスト管理しやすい形式（UTF-8, カンマ区切り）を採用する。
- ハザードレイヤは共通の座標系に変換した SVG とし、ベースマップと位置が一致するように作成する。

---

## 2. 避難所CSV仕様

### 2.1 ファイル形式

- 文字コード: UTF-8
- 区切り文字: `,`（カンマ）
- 1行目: ヘッダ行（列名）

### 2.2 カラム仕様（案）

| 列名         | 型       | 必須 | 説明                                       |
|--------------|----------|------|--------------------------------------------|
| `id`         | string   | 必須 | 一意なID（数値でもよいが文字列として扱う） |
| `name`       | string   | 必須 | 避難所名称                                 |
| `lat`        | float    | 必須 | 緯度（十進表現）                           |
| `lon`        | float    | 必須 | 経度（十進表現）                           |
| `type`       | string   | 必須 | 種別（`general`, `welfare`, `wide` など）  |
| `address`    | string   | 任意 | 住所                                       |
| `capacity`   | int      | 任意 | 想定収容人数                               |
| `barrier_free` | boolean | 任意 | バリアフリー対応（`true`/`false`）        |
| `pets`       | boolean  | 任意 | ペット同行可否（`true`/`false`）          |
| `updated_at` | string   | 任意 | 更新日（`YYYY-MM-DD` フォーマット）       |

※ 実際の自治体オープンデータに合わせて列名・型を調整する。

# 01_overview: 防災マップシステム概要

## 1. システム名称

- 仮称: **岡山防災マップシステム（SVGMap + Next.js）**

## 2. 目的

- 岡山県内、とくに岡山市周辺の住民・関係者に対して、  
  **避難所・ハザード情報・（将来）リアルタイム情報**を一元的に閲覧できる Web 防災マップを提供する。
- SVGMap のハイパーレイヤリングを用いて、  
  **国・岡山県・岡山市・研究室など複数ソースの地図レイヤを一画面に統合表示**する。
- Next.js により、**モダンで拡張しやすい UI** を実現し、将来的な機能追加（センサ連携、カメラ、通知など）に対応しやすい構成とする。

## 3. 対象ユーザ

- 岡山県内の一般住民  
  - 自宅・職場の危険度や最寄り避難所の位置を知りたい人
- 大学・研究機関の関係者  
  - 岡山地域の防災情報を可視化・分析したい人
- 自治体職員・防災担当者（岡山市・岡山県など）  
  - 避難計画の検討、防災啓発資料の作成、訓練時の説明資料として利用

## 4. 利用シナリオ（例）

### 4.1 一般住民

1. トップページから岡山防災マップを開く。
2. 検索バーに自宅住所（例: 岡山市北区〇〇）を入力し、地図をズームさせる。
3. 「洪水」「土砂災害」レイヤをONにして、自宅が想定浸水区域や警戒区域に入っているかを確認する。
4. 「避難所」レイヤをONにして、徒歩圏内の避難所を確認する。
5. 必要に応じて画面を印刷し、家族と共有する。

### 4.2 自治体職員

1. 管理画面にログインする。
2. 岡山市または岡山県が公開している最新の避難所一覧CSVをアップロードし、プレビューで位置と属性を確認する。
3. 問題がなければ「公開」ボタンを押して本番マップに反映する。
4. 岡山県が更新したハザードマップに合わせて、対応するSVGレイヤを差し替える。

### 4.3 研究用途

1. 研究室で岡山地域で収集したセンサデータやカメラ位置を CSV レイヤとして追加する。
2. 一般のハザードレイヤと重ねて、過去の豪雨や地震時の状況を分析する。
3. 研究成果を画面キャプチャや印刷で資料化する。

## 5. スコープ

### 5.1 本バージョンで対応する範囲（MVP）

- 対象地域: **岡山県（当面は岡山市および周辺市町村を中心）**
- ベースマップ表示（岡山県内の道路・河川・行政界）
- 以下のレイヤ表示
  - 岡山市および岡山県が指定する避難所（ポイント）
  - 岡山県内の洪水浸水想定区域（ポリゴン）
  - 岡山県内の土砂災害警戒区域（ポリゴン）
- 避難所詳細表示（名称・住所・種別・収容人数など）
- 住所 or 施設名による簡易検索（岡山県内を対象）
- 管理画面からの避難所CSV更新

### 5.2 将来拡張（この仕様書では設計だけ/実装は任意）

- 気象庁・国交省等のデータを利用した気象レーダー・河川水位との連携（岡山県内の観測点）
- 岡山県内の主要河川のライブカメラ映像との連携
- 危険区域を避けた避難経路ナビゲーション
- PWA化・プッシュ通知（岡山県内の警報・避難情報）

## 6. システム構成概要

- フロントエンド
  - Next.js（TypeScript想定）
  - `/map` ページに SVGMap ビューアを埋め込み
- 地図エンジン
  - SVGMap.js（必要に応じて SVGMap GISモジュール）
  - Containers.svg / 各種レイヤSVG / CSV + WebApp Layer
- データ
  - 避難所: 岡山市・岡山県の避難所オープンデータをベースにしたCSV
  - ハザード: 岡山県内のハザードSVGレイヤ（共通schema）
  - 座標スキーマ(schema): 岡山県を対象とした共通の投影座標系/EPSGに基づき定義

## 7. 非機能要件（概要）

- 対応ブラウザ: 最新の Chrome / Edge / Firefox / (スマホ) Chrome, Safari
- PC・スマホ対応のレスポンシブWebデザイン
- 操作応答時間: ズーム・パン・レイヤON/OFFなどの基本操作で体感0.5秒以内を目標
- 管理画面は認証必須（ID/パスワード）

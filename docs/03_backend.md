# 03_backend: バックエンド仕様（段階的ロードマップ）

## 1. 目的

本ドキュメントは、岡山防災マップシステムにおけるバックエンドの役割と構成を、**段階的に拡張可能な形で定義**することを目的とする。

- 初期段階では「ほぼバックエンドなし」で構成し、**静的な防災マップ**を素早く構築する。
- その後、管理機能・検索機能・リアルタイム情報連携などを、**フェーズごとに追加できるようにする**。

バックエンドの詳細実装（言語・フレームワーク）は、この仕様書では固定しないが、Next.js の API Routes または Node.js/Express 等を想定して記述する。

---

## 2. 段階別のバックエンド構成方針

本システムのバックエンドは、以下の3段階で拡張していくことを想定する。

- **段階 0**: バックエンドなし（静的ファイル＋Next.js のみ）
- **段階 1**: 薄いバックエンド（管理・検索 API）
- **段階 2**: リアルタイム情報ハブ（災害・天気・交通 等）

それぞれの段階の仕様を以下に示す。

---

## 3. 段階 0: バックエンドなし構成

### 3.1 目的

- 可能な限りシンプルな構成で、**岡山防災マップの基本機能**を動作させる。
- サーバサイドの実装負荷を抑え、**UI・地図レイヤ構成・データ形式**に集中する。

### 3.2 アーキテクチャ

- Next.js
  - `/map` ページなどフロントエンドのみ実装
  - 静的サイト（SSG）または軽い SSR を想定
- データ
  - 避難所: `map/data/shelters_okayama.csv`
  - ハザード: `map/layers/hazard_flood_okayama.svg`, `map/layers/hazard_landslide_okayama.svg` 等
  - Containers: `map/containers/Containers.svg`
- 地図表示
  - フロントエンドから、`public/map/` 相当の静的ファイルを `fetch` して表示
  - 検索・フィルタも **ブラウザ内で CSV をパースして実行**

### 3.3 機能面の制約

- 管理機能
  - Web からの CSV アップロード・編集は**行わない**
  - データ更新は「Git で CSV / SVG を差し替える」運用とする
- 認証
  - 管理者ログイン機能は未実装
- 外部API連携
  - 災害情報・天気・交通などのリアルタイム情報は**扱わない**  
    （必要であればフロントから直接閲覧できる外部サイトのリンクを案内する程度）

### 3.4 段階 0 のゴール

- `/map` ページで以下が確認できる状態：
  - 岡山のベースマップ表示
  - ハザードレイヤ（洪水・土砂）の重ね合わせ
  - 避難所ピン表示＋簡易フィルタ（ブラウザ側ロジック）
- データ仕様は `docs/04_data_spec.md` に従って整備されている。

---

## 4. 段階 1: 薄いバックエンド（管理＋検索 API）

### 4.1 目的

- 最低限のバックエンドを追加し、
  - **管理画面からの CSV 更新**
  - **検索・フィルタのAPI化**
  を可能にする。
- 運用担当者が「Git を直接触らなくても避難所データを更新できる」状態を目指す。

### 4.2 想定技術

- 選択肢 1: Next.js の API Routes を使用
  - フロントエンドと同一リポジトリ・同一プロセスで完結
- 選択肢 2: 別プロセスの API サーバ（例: Node.js/Express, Python/FastAPI 等）
  - 将来の拡張性を優先する場合に選択
- この仕様では、**エンドポイントの形のみ定義**し、実装技術は後から選択可能とする。

### 4.3 エンドポイント仕様（案）

#### 4.3.1 避難所検索 API

- `GET /api/shelters`

**クエリパラメータ（案）**

| パラメータ | 型     | 説明                                           |
|-----------|--------|------------------------------------------------|
| `q`       | string | 名称・住所などのキーワード（部分一致検索）     |
| `type`    | string | 避難所種別 (`general`, `welfare`, `wide` 等)   |
| `limit`   | int    | 取得件数上限（デフォルト 100 件など）         |
| `bbox`    | string | 表示範囲のバウンディングボックス（任意）      |

- 戻り値: JSON  
  - `docs/04_data_spec.md` の避難所CSVと同等の項目を持つオブジェクト配列。

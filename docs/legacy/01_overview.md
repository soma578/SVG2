# 01_overview: 防災マップシステム概要

> Legacy document: この文書は MapLibre 併用時代の設計記録です。現在の `native` ランタイム契約は `docs/map-runtime-contract.md` を参照してください。

## 1. システム名称

- 仮称: **防災マップシステム（SVGMap overview + MapLibre detail + Next.js）**

## 2. 目的

- 防災関連情報および現場の活動状況を、地図上で直感的に可視化する Web 防災マップを提供する。
- 静的な地図ではなく、データ更新に応じて表示が切り替わる動的マップを目指す。
- 本システムは、以下の 3 つの主要業務レイヤーを中心に構成する。
  - **L1: ベースエリア**
    - 自治体境界、地区境界、区域情報などの基礎面情報
  - **L2: 避難所**
    - 指定避難所の位置に加え、施設名、住所、収容人数、施設種別、開設状況などの属性情報を保持するポイント情報
  - **L3: チーム活動**
    - 支援チームの現在地、活動地点、活動状況などの動的ポイント情報
- 洪水、土砂災害、気象、避難経路などは、必要時に重ねる**補助レイヤー**として扱う。
- region-aware な asset / config / data 運用を前提にし、CSV / Excel 取込、管理画面連携、将来の LoD / QTCT へ拡張しやすい構成とする。

## 3. 対象ユーザ

- 地域住民
  - 自宅・職場周辺の危険度や最寄り避難所の位置を知りたい人
- 大学・研究機関の関係者
  - 対象地域の防災情報を可視化・分析したい人
- 自治体職員・防災担当者
  - 避難計画の検討、防災啓発資料の作成、訓練時の説明資料として利用する人
- 現場支援チーム・関係者
  - 活動地点や支援状況を把握・共有したい人

## 4. 利用シナリオ（例）

### 4.1 一般住民

1. トップページから防災マップを開く。
2. 全国 overview または都道府県 overview で対象地域を絞る。
3. 市区町村詳細で L1 ベースエリア、L2 避難所、L3 チーム活動を確認する。
4. 必要に応じて補助レイヤを重ねる。

### 4.2 自治体職員・防災担当者

1. 管理画面にログインする。
2. 避難所一覧 CSV / Excel をアップロードし、位置と属性をプレビューする。
3. チーム活動 CSV / Excel をアップロードし、地図上で位置・状態を確認する。
4. 問題がなければ公開し、本番マップへ反映する。

### 4.3 研究用途

1. 研究室で収集した拠点・観測点などを追加レイヤとして投入する。
2. L1 / L2 / L3 と補助レイヤを重ね、地域防災上の分析や検討を行う。
3. 結果を資料化する。

## 5. スコープ

### 5.1 本バージョンで対応する範囲

- 対象地域:
  - 既定 region は岡山
  - `regions/<regionId>/manifest.json` により追加 region を段階導入できる
- 3階層ビュー:
  - 全国 overview
  - 都道府県 overview
  - 市区町村詳細
- 以下の主要レイヤ表示
  - **L1 ベースエリア**
  - **L2 避難所**
  - **L3 チーム活動**
- 主要レイヤの ON / OFF 切替
- 選択地物の詳細表示
- `?region=` による region 切替
- CSV / Excel を入力元とした L2 / L3 データ取込
- 管理画面からの L2 / L3 データ更新
- 洪水・土砂災害など補助レイヤの重ね合わせ表示（任意）

### 5.2 将来拡張

- 気象庁・国交省等のデータを利用した気象レーダー・河川水位との連携
- 危険区域を考慮した避難経路表示
- PWA 化・通知機能
- L3 のリアルタイム更新
- LoD / QTCT による縮尺連動表示

## 6. 階層表示方針

- 本システムは、全国規模への拡張可能性を考慮し、地図表示を以下の 3 階層に分ける。
  - 全国 overview
  - 都道府県 overview
  - 市区町村詳細
- 全国 overview では都道府県境界を表示する。
- 都道府県 overview では県内市区町村境界を表示する。
- 市区町村詳細では L1 / L2 / L3 の個別表示と詳細確認を可能にする。
- basemap は市区町村詳細でのみ表示し、全国 overview と都道府県 overview では表示しない。

## 7. システム構成概要

### 7.1 オンライン / オフライン対応

- オンライン時は対象 region の最新データ取得を試みる。
- 取得成功時は表示データと端末内キャッシュを更新する。
- 取得失敗時は端末内キャッシュを利用する。
- キャッシュも存在しない場合は `regions/<regionId>/...` 配下の fallback データを利用する。
- オフライン時はキャッシュ優先で表示し、利用者へ表示元と最終更新時刻を明示する。

### 7.2 フロントエンド

- Next.js（TypeScript）
- `/map` ページに overview / detail の state machine を持つ

### 7.3 地図描画基盤

現行の責務分担:

- **SVGMap**
  - 全国 overview
  - 都道府県 overview
- **MapLibre**
  - 市区町村詳細

補足:

- これは current path の意図的な落としどころである
- 将来的に SVGMap ネイティブへさらに寄せる余地はあるが、本仕様では current path を正本とする

### 7.4 データ

- L1 ベースエリア:
  region manifest が指す SVG / 辞書 / 補助 index
- L2 避難所:
  CSV / Excel を入力元として正規化した JSON
- L3 チーム活動:
  CSV / Excel を入力元として正規化した JSON
- 補助レイヤ:
  洪水、土砂災害、気象、避難経路など

### 7.5 region 構成

- `regions/index.json`
- `regions/<regionId>/manifest.json`
- `regions/<regionId>/runtime-config.json`
- `regions/<regionId>/district-dict.json`
- `regions/<regionId>/shelters-fallback.geojson`
- `regions/<regionId>/team-activity-fallback.json`

## 8. 非機能要件（概要）

- 対応ブラウザ:
  最新の Chrome / Edge / Firefox / Safari
- PC・スマホ対応のレスポンシブ Web デザイン
- overview は軽量 SVG を前提とする
- detail は basemap を含む実用的な詳細表示を優先する
- 管理画面は認証必須（現行は HTTP-only cookie session）
